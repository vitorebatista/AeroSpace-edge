# aerospace-edge test-not

Negative condition evaluation utility

## Synopsis

```synopsis
aerospace-edge test-not [-h|--help] <lhs> = <rhs>
aerospace-edge test-not [-h|--help] <lhs> ~= <rhs>
```

## Description

Negative condition evaluation utility

The subcommand works exactly the same as the [`test`](test.md) subcommand, except the result (exit code) is negated. Please refer to the [`test`](test.md) subcommand documentation for more information.
